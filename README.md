# Professional Unit Converter

This is a professional unit conversion web app built using **Streamlit, Pint, and OpenCV**. The app provides a sleek UI with **real-time unit conversion** and **a frosted glass effect** for input fields.

## 🚀 Features
- Supports multiple unit categories (Length, Mass, Temperature, etc.)
- Uses **Pint** for accurate conversions
- Stylish UI with **custom CSS** and a **background image**
- Built-in **error handling** for invalid conversions
- **Streamlit balloons 🎈** for successful conversions
